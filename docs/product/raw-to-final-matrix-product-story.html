XIC Extractor product story

從 RAW 到 Final Matrix：一個 DNA adduct 如何被偵測、定量、寫入矩陣

這份文件用白話講完 XIC Extractor 的完整產品流程： Discovery 可從 MS2 neutral-loss 或 MS1 delta-pattern evidence 開始；候選證據必須先進入 EvidenceVector / PeakHypothesis 與 model selection，之後才可能經過 integration、跨樣本 alignment 與授權 projection 寫入 alignment_matrix.tsv。

適用情境

本工具設計用於 DNA adductomics 分析。特徵通常為低豐度、 sparse detection（單一樣本檢出是常態而非例外）， release 路徑目前仍以 CID neutral-loss 為主要辨識策略；Pt MS1 pattern 仍是 diagnostic_only 方法開發，不是 Final Matrix intake。

一張圖看完整條路

產品流程分成兩層：單樣本層負責從 RAW 中找出候選特徵、抽取色譜圖、選峰、 積分面積；跨樣本層負責把多支樣本的觀察對齊成同一個 matrix row， 補缺值、處理重複宣告，最後決定哪些定量值可以進 primary matrix。

1. Discovery evidence providers CID-NL 讀 MS2；Delta Mass / Pt 從 sample-local MS1 features 提出候選證據。
2. XIC / trace evidence 對候選 m/z 回 RAW 拉局部 trace，保留 shape、boundary、RT 與 provenance facts。
3. EvidenceVector + PeakHypothesis 把候選 assignment 與相關證據組成可稽核的 alternatives；候選不等於已選峰。
4. Model selection + IntegrationResult 選擇可支持的 hypothesis；只有 selected peak 才產生邊界與面積結果。
5. Workflow projection 工作流把已選結果投影成 sample-local owner 或 review；未授權 evidence 停在這裡。
6. Cross-sample 分群 跨樣本比對 owner，以 m/z + RT + tag 閘門將相同特徵歸入同一 family。
7. Backfill 對 family 中沒檢出的樣本回 RAW 搜尋，嘗試 rescue。
8. Claim + 合併 處理重複宣告（同一峰被多個 row 搶）、合併跨 tag 的同族 family。
9. Production 決策 逐 row/cell 決定是否寫入 primary matrix，留空或標記為 review。
10. Final Matrix 輸出 alignment_matrix.tsv 供下游校正與統計。
白話版： 不是「找到 pattern 或峰就填入矩陣」。每個候選要先成為帶 provenance 的 evidence / hypothesis，再於樣本內通過 model selection 與 integration， 再在跨樣本層通過 grouping、backfill、claim 與 identity 檢查，最後才由 production decision 放行。
Pt 方法目前停在哪裡： Pt candidate generation、same-scan window support、anchor-local trace evidence、 trace_rule_call 與人工 review 都是 diagnostic_only。 它們尚未建立完整 assignment alternatives、canonical PeakHypothesis selection、產品 IntegrationResult 或 workflow projection，因此不會進入下面的 Alignment / Matrix 路徑。

1Discovery：找出 RAW 中的候選特徵

Discovery 的任務是從 RAW 中辨識出可能的 DNA adduct 候選特徵。 CID-NL 是目前 release intake；Delta Mass / Pt 是並列的診斷方法實作，可獨立或與 CID-NL 組合產生 review evidence：

策略一：CID Neutral-Loss（MS2 層級）

掃描 RAW 中所有 MS2 光譜，計算碎裂離子與前驅離子的質量差。 若差值符合已知 neutral-loss tag（如 dR = 116.047 Da）， 則該前驅離子被記錄為 seed。

  • 多個 seed 若來自同一前驅離子（不同 scan 重複觸發），以 m/z 容差分群。
  • 每組回 MS1 查詢同位素分布，確認精確 m/z 並鎖定峰位。
  • 產出 discovery_candidates.csv。

策略二：Delta Mass Pattern（MS1 層級）

在 MS1 已偵測特徵中搜尋特定 m/z 間距模式。 目前實作的是 Pt pattern： base / +1 / +2 / +4 Da 四個位置必須同時存在， 符合鉑類藥物的同位素分布特徵。

  • 輸入：sample-local 已偵測 MS1 features（可來自內部或外部工具如 MZmine）。
  • 硬閘門：m/z ppm 容差 + RT 秒容差 + 訊號品質門檻。
  • 不接受部分匹配——四個位置全到才算 candidate。
Composite 診斷策略： 兩種策略可以組合使用（如 pt_pattern_cid_nl_dr preset）： delta mass 負責 MS1 模式匹配，CID-NL 提供 MS2 碎裂證據作為 base evidence 支持。 Preset 系統（TOML 檔案）定義每個策略的 tag、容差與組合模式；這個 preset 的存在不等於 detector activation。
Discovery 策略與 Alignment 的關係： 目前已 release / 預設的 alignment intake 仍以 CID-NL discovery 產出的 discovery_candidates.csv 為主。Delta mass / Pt pattern candidates 在沒有 activation 或 export contract 前不直接變成 alignment 或 Matrix authority—— 它們目前只提供 diagnostic_only MS1 pattern / trace / review evidence； trace_rule_call 是診斷機器評估，不是 final detector call。 在 composite 模式下，CID-NL 可作為 base evidence 支持。 Product ion（HCD-PI）策略已在型別系統中定義但尚未實作。
輸入 → 輸出： CID-NL：RAW 檔 → discovery_candidates.csv + discovery_batch_index.csv。 Delta Mass：Detected Features CSV（內部或外部 MS1 feature table） → Pt candidate CSV + evidence CSV。

2XIC 抽取：回 RAW 拉色譜圖

對每個 discovery candidate，用其 m/z ± 容差視窗回 RAW 抽取 extracted ion chromatogram (XIC)。產出的 trace 是一組 (RT, intensity) 陣列， 代表該 m/z 在層析維度上的訊號分布。

抽取方式

從 RAW 讀取 MS1 光譜，對目標 m/z ± ppm window 做 chromatogram extraction。 支援批次化處理（多目標共享同一次 RAW 存取）以提升 I/O 效率。

Alignment 中的抽取

Alignment pipeline 內建 XIC 抽取（owner build 與 backfill 各一次）， 不需要另外跑 extraction script。每個 sample-local owner 的 trace 就是在這一步產生的。

3Peak 選擇與積分：從 trace 到面積

這一步解決的問題是：在一段 XIC trace 裡可能有多個局部峰， 到底哪一個是我們的目標峰？選出後如何正確計算面積？

候選峰偵測

從 XIC trace 中用 local-minimum 方法找出所有可能的候選峰邊界， 每個候選峰由 (left, apex, right) RT 三元組定義。

評分與選擇

對候選峰評分（S/N、峰形、對稱性）， 結合 RT prior（來自 discovery 或 library）選出最佳 selected peak。

AsLS 積分

用 Asymmetric Least Squares (AsLS) 基線校正後積分， 產生 baseline-corrected area。Morphology area 則是對 AsLS 殘差做 Gaussian smoothing（15 點窗）後只取正值積分， 是 primary matrix 的面積來源。

輸出： 每個 candidate 得到一個 IntegrationResult， 包含 RT 邊界、高度、raw area、AsLS-corrected area、morphology area。 這裡描述的是已授權的一般 peak-selection 路徑；目前 Pt diagnostic artifacts 尚未投影為產品 IntegrationResult。

4跨樣本 Alignment：Owner → Family → Matrix Row

Alignment 的核心問題是：不同樣本中看到的 peak observations， 哪些其實是同一個化合物？這一層用漏斗式規則逐步收斂。

步驟 做什麼 為什麼要這步
aOwner 建構 同一樣本中，屬於同一個 MS1 chromatographic peak 但被多次 MS2 觸發的 candidates 合併為一個 owner。 解決「重複觸發」問題：同一個前驅離子在不同 scan 被碎裂多次， 本質上只算一個觀察事件。
bCross-sample 分群 用 complete-link clustering 比對不同樣本的 owners。 閘門：m/z 50 ppm、product m/z 20 ppm、相同 neutral-loss tag、RT scoring。 把跨樣本的「同一個化合物」歸入同一個 feature family，作為 matrix 的一行。 Tag 閘門保證每個 NL transition 獨立處理。
cBackfill 對 family 中沒有 detected 的樣本，用 family 的 seed（m/z, RT） 回 RAW 重新抽取 XIC、嘗試找峰。 Discovery 不一定抓到所有樣本中的弱訊號。Backfill 讓 matrix 能填補 「有可能存在但 MS2 沒觸發」的觀察。成功找到的 cell 標記為 rescued。
dClaim Registry 檢查同一樣本中是否有多個 family row 搶同一個 MS1 peak（5 ppm fuzzy match）。 若有，指定 winner 並把 loser 標記為 duplicate。 Backfill 後可能出現「兩個 family 其實共用同一個 MS1 峰」的情況。 不處理會導致同一個峰的面積被重複計算。
ePrimary 合併 跨 neutral-loss tag 的 family，若 precursor m/z 與 RT 高度接近， 合併為同一個 primary family（一個化合物掉多種碎片）。 Step b 的 tag 閘門會把同一化合物的不同 NL transition 分成不同 cluster。 Backfill 完成後才能安全合併，因為每個 NL 需要獨立 backfill（tag-specific product m/z）。
fMatrix Identity 評估每個 family 的 identity evidence 強度，決定是否進 primary matrix。 產出 identity_decision（production / provisional / audit） 與 identity_confidence（high / medium / review）。 不是所有 family 都有足夠證據進入最終矩陣。 單一樣本檢出可以保留為 provisional discovery 供 review，但本身不是 primary matrix authority。
gProduction 決策 對 matrix 中每個 cell 做最終判定：寫入面積、留空（blank）、 或標記為 duplicate/ambiguous/absent。 Cell-level 的品質控制。即使 row 被納入 primary matrix， 個別 cell 仍可能因為品質問題被留空。
漏斗規則的關鍵設計： tag 閘門在 Step b 刻意分開不同 NL transition → 各自獨立 backfill → Step d 發現共享 MS1 peak → Step e 合併回同一個 family。 這個順序反映 LC-MS/MS 的物理事實：一個化合物可以碎出多種 fragments， 每種 fragment 的 product m/z 不同，必須分別回 RAW 搜尋。

5Final Matrix：誰能寫入、誰被留空

最終產出的 alignment_matrix.tsv 是一個 feature × sample 矩陣， 每個 cell 放的是 production-accepted area（或空值）。 這不是 raw detection dump，而是經過完整品質控制後的定量結果。

面積值來源

Primary matrix 面積使用 morphology area： 對 AsLS baseline residual 做 Gaussian smoothing（15 點窗）後， 只取正值部分積分。如果 morphology area 不可用，該 cell 留空—— 不回退到 AsLS corrected area 或 raw area。 每個 cell 記錄面積來源（primary_matrix_area_source）。

留空原因

Cell 可能因為 absent（backfill 找不到）、 duplicate（另一個 family 已宣告該峰）、 ambiguous（多個候選峰無法區分）等原因被留空。 每個留空 cell 都帶有 blank_reason。

Identity Decision 分級

Decision 意義 進入 primary matrix？
production_family 有足夠 identity evidence 支持，是正式的 matrix row。 是
provisional_discovery Evidence 不足以納入 primary matrix（如零檢出、extreme backfill dependency）。 否（進 review surface）
audit_family 有特殊旗標需要人工審查。 否（進 audit surface）
Single-sample detection 政策： 在 DNA adductomics 情境下，僅在單一樣本中檢出的特徵 （single_sample_local_owner）仍值得保留與人工 review， 但只標記為 provisional_discovery，不寫入 primary matrix。 後續必須取得額外 identity evidence，才能升為 production_family。

關鍵設計決策

這些決策不是偶然——它們反映了 LC-MS/MS adductomics 的物理事實與分析需求。

為什麼 discovery 不直接寫 matrix？

Discovery 提供的是 per-sample candidate 與 evidence，不是自動成立的 counted detection。 候選必須先通過 PeakHypothesis model selection / integration；是否值得成為 matrix 的一行，還需要跨樣本 evidence （grouping coherence、backfill 結果、duplicate 檢查）才能決定。 兩者是不同層級的判斷。

為什麼 backfill 要在 clustering 之後？

必須先知道「跨樣本的同一個 family 長什麼樣」（m/z, RT seed）， 才能用正確的參數去缺失樣本的 RAW 搜尋。 先 backfill 再 cluster 會用錯 seed。

為什麼 NL tag 是硬閘門？

不同 neutral-loss 代表不同碎裂途徑，product m/z 不同， backfill 需要 tag-specific 的 product m/z 做搜尋。 clustering 時不能混在一起，否則 backfill 結果語意不對。 合併在 backfill 之後（Step e）才安全。

為什麼保留單一樣本檢出？

DNA adductomics 的分析對象是低豐度加合物。 文獻建議 minFraction 低至 0.05–0.10（XCMS adductomics 參數推薦）。 在 discovery 階段直接丟棄會系統性失去真實但稀有的 adducts。 因此單樣本檢出會保留到 review surface，但不因此取得 Matrix 寫入權。
