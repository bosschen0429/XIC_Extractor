這是科學責任與資料交接圖，不是每個函式的執行時序。若小螢幕不易閱讀，可另開完整圖；也能沿下方問題摘要讀完同一條流程。

  • 共用，不等於方法盲目一致共享觀察、群組與格值的責任；搜尋與解讀仍可採用明確的方法策略。
  • 回填不是猜值回到缺格樣本尋找本地訊號，不拿其他樣本的面積推算缺值；找到後仍要判斷能否使用。
  • 數值與偵測分開有面積不一定計入偵測；需要檢閱也不等於數值被否決。結果要連同狀態與理由閱讀。

03 · 共同判斷

每一步回答不同問題

哪些訊號值得追查？

Discovery 依方法提出候選；峰證據提供邊界與面積。候選還不是已鑑定化合物。

看候選與峰的例子 →

不同樣本能對上嗎？

Alignment 比較本地觀察；有既有脈絡且需要時，Backfill 才重訪缺格，不從別人的面積猜值。

看跨樣本與缺格 →

這個格值怎麼解讀？

可用面積、計入偵測與需要檢閱分開判斷；空白也不等於零。
