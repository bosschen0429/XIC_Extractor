XIC Extractor · 處理原理

兩個樣本有峰，
第三個為什麼缺格？

從 A、B 的候選峰與 C 的缺格出發，依序問：看到什麼、能否對應、能量到多少，以及結果該如何使用。這是理解順序，不是函式執行時序。

這篇回答「為什麼」

要實際操作，請先走 Targeted 或 Untargeted 指南。只想看全貌，可讀 一頁處理地圖。

找候選看峰與面積跨樣本對應重訪缺格解讀判斷使用結果詞彙速查

先把問題說清楚

A、B 出現 m/z 與 RT 接近的峰，C 在相應位置沒有可用結果。我們不知道三者是否真屬於同一化合物，也不知道 C 是沒有訊號、尚未搜尋，還是有訊號卻不能量化。以下是示意案例，不是某批 RAW 的驗證結論。

候選訊號→峰與面積→跨樣本對應→必要時重訪→結果與使用

看見峰、成為成員、得到數值，是三個問題

01

Discovery：哪些訊號值得往下看？

探索方法決定用什麼線索提出候選。候選保留值得追查的訊號，不是化合物鑑定，也不是最後結果格。

方法決定搜尋證據

CID-NL 可以從 MS2 中性流失線索出發；其他方法可以使用不同的證據。方法的存在、候選輸出與定量支援是不同的事，適用範圍需個別確認。

A 有候選，還沒有跨樣本身分

A 的線索指向一段 MS1 訊號。此時可以記錄候選與來源，但不能只因 B 的 m/z 接近，就說它們是同一個 feature。

精確候選與方法邊界：Discovery；設定：Preset 參考。

02

峰與面積：這段訊號能量到什麼？

XIC 是指定 m/z 範圍的強度隨時間變化的曲線。系統要在曲線中辨認可支持的峰、邊界與面積，不能直接把整個搜尋區間積分。

搜尋範圍不等於積分範圍

搜尋窗用來找訊號，候選區間提出峰的位置，定量脈絡提供判讀完整峰形所需的資料。平滑、baseline、邊界與積分有一致的物理訊號規則。

A 的峰翼被切到怎麼辦？

局部候選若只含一部分峰，需要足夠的周邊 trace 才能判讀邊界。較大的面積或較漂亮的峰，不能單獨證明它就是這個目標。

精確規則：定量脈絡、訊號處理理由與 面積規則。

03

Alignment：A、B 能放在同一列嗎？

跨樣本對應需要比較本地峰與共同證據。m/z、RT 接近可以支持比較，不能各自單獨證明同一化合物。

對應不是鑑定

Alignment 判斷哪些觀察可組成同一個 feature、哪些應分開、哪些仍未解決。批次 RT 漂移與本地峰位置是不同資訊，不能用預測位置替代實際觀察。

先解決 A、B 的關係

如果 A、B 附近還有競爭峰，需要保留競爭與不確定性，而不是把所有近峰合成已確認身分。建立可用群組脈絡後，才有依據追查 C 的缺格。

方法原則、現行做法與未解問題：Alignment；候選與群組的差別：峰錨點與群組邊界。

04

Backfill：C 的缺格能找回來嗎？

回填是在已有目標或群組脈絡下，有限度地重訪 C 的本地訊號。它不是用 A、B 的面積推算 C，也不是每個格都必須執行的一步。

找回觀察，還要判斷能否使用

重訪可能找到峰，也可能沒有可用結果。找到的觀察仍需判斷對應與可量化性；回填本身不創造新群組，也不直接決定最終值。

C 的三種可能

有本地證據且後續判斷支持時，C 可得到有來源的數值；訊號不足或對應不明時，可保留無可用值；未搜尋與已搜尋但沒有結果也不能混為一談。

重訪條件、觀察結果與套用邊界：Backfill。

05

有面積、計入偵測、需要檢閱，是同一件事嗎？

不是。面積回答量到多少；counted detection 回答是否符合工作流的偵測判定；review 表示哪些結果值得再看。三者可以有不同答案。

分數不能代替必要證據

分數可以在可比較的候選之間排序，不能把缺失的證據變出來。零是數字；空白不自動代表零或化學不存在。判讀時要一起看來源、狀態與理由。

C 有數字，也不一定能直接算偵測率

即使 C 保留了可用面積，是否計入偵測仍由工作流規則判定。反過來，一筆已計入的結果也可能需要檢閱。看到回填表的面積，不能先假定主矩陣一定用了它。

精確判斷：Decision Policy；Targeted 的選擇與計數：Targeted Selection。

06

兩種入口，共用判斷，不同交付

Targeted 已有目標表，搜尋受到目標約束、結果對應固定目標；Untargeted 依方法探索，再從成立的群組形成 feature 列。兩者共用峰證據、跨樣本關係與格值判斷，不代表所有方法的證據解讀都相同。

正式交接與投影順序：Domain Glossary、Decision Policy。要查模組與依賴，再讀 系統導覽。

07

Matrix 是完成判斷的結果，不是所有候選的集合

Untargeted 的主矩陣交付 feature × sample 數值；判讀所需的來源與 review 資訊另有保存位置。候選、診斷表和檢閱圖不會因為看得到，就自動變成主矩陣格值。

格值、空白與伴隨資料：Quant Matrix；欄位：輸出參考。

08

讀懂結果後，下一步做什麼？

故事不在檔案寫出時結束。先確認交付內容，再檢閱影響判斷的項目，最後才使用數值。

Targeted：由整批縮到單筆

先看 workbook 摘要，依提示看需檢查結果，必要時在工作台查看 XIC；面積與內標關係用於預定計算。

09

需要查原始文件時，再認識這些名稱

PeakHypothesis：對某個峰及其證據的假說，不等於已確認的化合物。

CrossSample：管理跨樣本群組與成員的科學責任。

ObservationRevisit：依既有脈絡重訪本地觀察，不是插值。

ProductionCellDecision：對明確的目標／群組格子，決定可用數值或不寫入的理由。

完整定義查 Domain Glossary，不必先背完才能操作。
