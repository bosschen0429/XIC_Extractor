XIC Extractor product story

從 RAW 到 Final Matrix：一個 DNA adduct 如何被偵測、定量、寫入矩陣

這份文件以 Untargeted CID-NL 為例，說明 XIC Extractor 如何從候選走到定量矩陣： Discovery 可從 MS2 neutral-loss 或 MS1 delta-pattern evidence 開始；候選證據必須先進入 EvidenceVector / PeakHypothesis 與 model selection，之後才可能經過 integration、跨樣本 alignment 與授權 projection 寫入 alignment_matrix.tsv。

適用情境

DNA adductomics 是本頁的應用情境；稀有特徵可能只出現在少數樣本。 release 路徑目前仍以 CID neutral-loss 為主要辨識策略；Pt MS1 pattern 仍是 diagnostic_only 方法開發，不是 Final Matrix intake。

一張圖看完整條路

產品流程分成兩層：單樣本層負責從 RAW 中找出候選特徵、抽取色譜圖、選峰、 積分面積；跨樣本層先判斷哪些觀察屬於同一群組， 必要時在既有群組下補證據。完成每格答案後，才投影 Matrix 的列與樣本欄並發布。

展開逐步文字版流程
1. Discovery evidence providers CID-NL 讀 MS2；Delta Mass / Pt 從 sample-local MS1 features 提出候選證據。
2. XIC / trace evidence 對候選 m/z 回 RAW 拉局部 trace，保留 shape、boundary、RT 與 provenance facts。
3. EvidenceVector + PeakHypothesis 把候選 assignment 與相關證據組成可稽核的 alternatives；候選不等於已選峰。
4. 物理峰與選擇結果 保留 owner 已判定的峰邊界、可用面積及不確定性，不把候選直接當定量值。
5. 跨樣本比較準備 保留樣本與量測來源，使用已準備的 RT 漂移脈絡比較峰觀察。
6. Cross-sample 分群 在相容質量與 RT 脈絡下建立群組；保留衝突，不把相近就當成同一化合物。
7. Backfill 群組的直接支援達門檻後，對缺格進行有限度的觀察重訪。
8. 完成群組與樣本格證據 把原始與補搜觀察收完整；Backfill 本身不重建群組或選值。
9. 格值決策與投影 先完成 Feature × Sample 的數值或不寫入答案，再投影 Matrix 列與身分。
10. Final Matrix 輸出 alignment_matrix.tsv 供下游校正與統計。
白話版： 不是「找到 pattern 或峰就填入矩陣」。每個候選要先成為帶 provenance 的 evidence / hypothesis，再於樣本內通過 model selection 與 integration， 再完成跨樣本 grouping 與必要的 Backfill；Untargeted cell decision 先完成格值答案，projection 再建立輸出身分，writer 才呈現完成結果。
Pt 方法目前停在哪裡： Pt candidate generation、same-scan window support、anchor-local trace evidence、 trace_rule_call 與人工 review 都是 diagnostic_only。 它們尚未建立完整 assignment alternatives、canonical PeakHypothesis selection、產品 IntegrationResult 或 workflow projection，因此不會進入下面的 Alignment / Matrix 路徑。

1Discovery：找出 RAW 中的候選特徵

Discovery 的任務是從 RAW 中辨識出可能的 DNA adduct 候選特徵。 CID-NL 是目前 release intake；Delta Mass / Pt 是並列的診斷方法實作，可獨立或與 CID-NL 組合產生 review evidence：

策略一：CID Neutral-Loss（MS2 層級）

掃描 RAW 中所有 MS2 光譜，計算碎裂離子與前驅離子的質量差。 若差值符合已知 neutral-loss tag（如 dR = 116.047 Da）， 則該前驅離子被記錄為 seed。

  • 多個 seed 若來自同一前驅離子（不同 scan 重複觸發），以 m/z 容差分群。
  • 每組回 MS1 查詢同位素分布，確認精確 m/z 並鎖定峰位。
  • 產出 discovery_candidates.csv。

策略二：Delta Mass Pattern（MS1 層級）

在 MS1 已偵測特徵中搜尋特定 m/z 間距模式。 目前實作的是 Pt pattern： base / +1 / +2 / +4 Da 四個位置必須同時存在， 符合鉑類藥物的同位素分布特徵。

  • 輸入：sample-local 已偵測 MS1 features（可來自內部或外部工具如 MZmine）。
  • 硬閘門：m/z ppm 容差 + RT 秒容差 + 訊號品質門檻。
  • 不接受部分匹配——四個位置全到才算 candidate。
Composite 診斷策略： 兩種策略可以組合使用（如 pt_pattern_cid_nl_dr preset）： delta mass 負責 MS1 模式匹配，CID-NL 提供 MS2 碎裂證據作為 base evidence 支持。 Preset 系統（TOML 檔案）定義每個策略的 tag、容差與組合模式；這個 preset 的存在不等於 detector activation。
Discovery 策略與 Alignment 的關係： 目前已 release / 預設的 alignment intake 仍以 CID-NL discovery 產出的 discovery_candidates.csv 為主。Delta mass / Pt pattern candidates 在沒有 activation 或 export contract 前不直接變成 alignment 或 Matrix authority—— 它們目前只提供 diagnostic_only MS1 pattern / trace / review evidence； trace_rule_call 是診斷機器評估，不是 final detector call。 在 composite 模式下，CID-NL 可作為 base evidence 支持。 Product ion（HCD-PI）策略已在型別系統中定義但尚未實作。
輸入 → 輸出： CID-NL：RAW 檔 → discovery_candidates.csv + discovery_batch_index.csv。 Delta Mass：Detected Features CSV（內部或外部 MS1 feature table） → Pt candidate CSV + evidence CSV。

候選產生與方法邊界見 Discovery 正式文件；設定綁定見 Presets。

2XIC 抽取：回 RAW 拉色譜圖

對每個 discovery candidate，用其 m/z ± 容差視窗回 RAW 抽取 extracted ion chromatogram (XIC)。產出的 trace 是一組 (RT, intensity) 陣列， 代表該 m/z 在層析維度上的訊號分布。

抽取方式

從 RAW 讀取 MS1 光譜，對目標 m/z ± ppm window 做 chromatogram extraction。 支援批次化處理（多目標共享同一次 RAW 存取）以提升 I/O 效率。

Alignment 中的抽取

Untargeted application 安排 acquisition 與科學處理，不需要額外手動跑 extraction script。初始搜尋與必要的 Backfill 依各自請求取得 trace；相符的來源與查詢可重用 acquisition cache，不能假定每個候選固定開 RAW 兩次。

3Peak 選擇與積分：從 trace 到面積

Trace 可能包含多個峰。物理峰 owner 先判定可支持的峰區間、訊號品質與面積；方法與工作流再使用這些證據選擇假設。候選、已選峰和可寫入的格值是不同結果。

訊號準備

Gaussian 平滑與 AsLS baseline 各自從 raw trace 計算。正式訊號為平滑值減去非負 baseline，再將負值截為零；不是先扣 baseline 再平滑殘差。

峰與區間

物理峰 owner 依支持的 apex、谷底與 baseline-return 決定區間。缺少完整觀察脈絡或仍有歧義時保留不可用／不確定結果，不由 writer 補選。

面積與選擇

正式面積來自同一套 profile-bound physical signal 與 owner 接受的區間。已保存的 raw 或其他診斷面積可供比較，不能自動替代缺少的正式數值。

方法邊界：Pt 的 trace 與 review artifacts 仍是診斷證據，沒有因此取得 selected-area 或 Matrix 寫入權。能顯示曲線不等於已完成產品選峰。

精確公式、峰區間與可用性由 MS1 Morphology And Area Owner 維護；選擇規則見 Targeted Candidate Selection。

4跨樣本 Alignment：觀察 → 群組 → 樣本格

Alignment 比較不同樣本的峰觀察，建立有來源與不確定性記錄的群組。群組支持一個 feature row 的推論，並不單獨證明化合物身分。

步驟做什麼責任邊界
樣本內觀察整理同一樣本的物理峰與候選來源，保留精確的 acquisition 和方法 subject。重複包裝同一個峰不增加支援票數。
RT 比較脈絡Untargeted ordinary grouping 先用可信的 bootstrap 群與已知身分群估計批次 RT warp。Bootstrap 的 ordinary membership 不直接成為最終分群。
Window-band 分群重新比較相連質量鄰域內的 owners，依 RT 與量測質量建立 bands；每個 band 中同一樣本最多一個 owner。近似同分的競爭保留 undecided；singleton 留作 review。
有限度的 Backfill直接 SUPPORT 達群體門檻後，對缺格做有界搜尋，交出新觀察或 typed no-result。消費已關閉的群組結果；不重開 grouping，也不自己選 Matrix 值。
樣本格決策Projection 建立明確的 Target/Group cell subject，再由 ProductionCellDecision 選定數值或 no-write。Row 納入、格值與輸出格式各有 owner；writer 消費完成結果。
為什麼保留方法來源：相容的 CID-NL subjects 可以共享比較 workset，但每個 subject 保留自己的量測與 assessment。搜尋範圍、neutral-loss 名稱或相近 RT 都不能自行成為 feature 身分。

目前分群方法見 Alignment；共用交接順序見 Shared Processing Kernel。程式入口與模組責任由 架構責任表 維護。

5Final Matrix：誰能寫入、誰被留空

alignment_matrix.tsv 是完成決策後的 feature × sample 數值矩陣。Review、identity 與 evidence 詳情放在對應 sidecar；候選表或圖表不授予寫入權。

面積值來源

Cell decision 使用正式 owner 的可用數值與資格判定。有限且正值的 observed censored physical area 可在契約允許時使用，但必須保留截斷／偵測極限證據，不補造缺失訊號，也不因此變成 counted detection。

沒有數值也有意義

無可用觀察、尚未解決的競爭或不符合寫入條件，會留下 no-write。這與數值零不同；Backfill 找到訊號也不保證那個格一定可寫。

稀有特徵：Discovery 可以保留單樣本候選供 review。現行 ordinary grouping 的 singleton 為 review-only；候選存在或使用者看過曲線，都不是額外的 Matrix authority。

為什麼分開這些責任？

Discovery 提出候選

候選保留可能值得檢查的訊號；跨樣本群組、選定數值與產品寫入都需要後續 owner 的判斷。

Backfill 需要既有脈絡

先有 Target 或群組以及足夠的直接支援，才知道該到缺失樣本的哪個範圍尋找。重訪結果不能反過來創造自己的搜尋依據。

共享計算仍保留來源

不同方法 subject 可以共享相容的工作範圍，但每個 subject 的量測與證據判定仍須分清；排程或快取不能替代科學身分。

Writer 呈現完成結果

輸出 owner 負責欄位與檔案交付，不在最後一步重新讀 RAW、改選峰、補數值或推導新的群組。
