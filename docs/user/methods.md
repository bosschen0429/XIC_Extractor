# 分析方法

Untargeted 用分析方法決定找哪一類候選。選內建方法，或編輯後另存成自己的方法檔。

## 內建方法

| 方法 | 找什麼 | 產出 |
| --- | --- | --- |
| dR · DNA · 116.0474 Da | MS2 失去 dR（2'-deoxyribose）的離子 | 矩陣 |
| R · RNA · 132.0423 Da | MS2 失去 ribose 的離子 | 矩陣 |
| MeR · RNA · 146.0579 Da | MS2 失去 methylribose 的離子 | 矩陣 |
| Pt pattern · Delta Mass | 符合 Pt 同位素型態的 MS1 離子群 | 候選表 |
| Pt pattern ＋ CID-NL dR | Pt 型態且失去 dR 的離子 | 候選表 |

Delta Mass 方法只找候選，不做跨樣本對齊，也不產生矩陣。Pt 方法仍是暫定設定。

## 編輯方法

在 Untargeted 的 **分析方法** 按 **編輯方法**，開啟 **編輯分析方法**。

1. **名稱**：方法的名稱。
2. **CID-NL 中性丟失**：勾選這張卡，按 **＋ 中性丟失**，填名稱與中性丟失（Da）。
   - 兩個以上中性丟失時選 **組合**：**全部符合** 要求同一個峰全部見到，**任一符合** 見到一個即可。
3. **Delta Mass**：勾選這張卡，按 **＋ 伴隨離子**。
   - **基準** 是最輕的離子（Δ 0），所以 Δm/z 只能 ≥ 0。
   - 填法與 Targeted 相同，見[目標清單](target-list.md#delta-mass伴隨離子怎麼填)。
   - 離子角色與篩選門檻在 **進階：離子角色與篩選門檻**，預設值來自所選方法。
4. 按 **套用至批次設定**。

**套用至批次設定** 只改這一批。按 **保存批次設定** 或開始分析才會留存。

CID-NL 和 Delta Mass 同時勾選時，組合固定為兩者都要符合，中性丟失固定為 DNA_dR 116.0474 Da。

## 方法檔

方法可以存成 TOML 檔，給其他批次或其他人用。方法檔不含 RAW 與結果路徑。

- **另存方法檔…**（在 **編輯分析方法** 裡）：存成新檔。內建方法不會被覆寫。
- **方法檔案工具** → **匯入方法**：開啟 TOML 方法檔。
- **方法檔案工具** → **新增方法**：開啟名為「新方法」的草稿，預設一個 DNA_dR 116.0474 Da 中性丟失。

方法檔在程式外被修改後，要重新匯入才會生效。

## 只改這一次的參數

**調整本次方法參數** 可以改容差、最低強度比與分析 RT 範圍，只影響這一批。

- 預設分析每個 RAW 的完整採集範圍。要限制時，填 **限制分析 RT 範圍（選用）** 的起點或終點；留空的一端沿用 RAW 的起點或終點。
- 平常不需要改。改過的值會寫進另存的方法檔。
