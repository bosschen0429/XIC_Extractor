# 目標清單

列出要量的化合物。Targeted 讀全部列；Untargeted 只讀 `role` 為 `istd` 的列，當作內標。

## 取得範例

- 工作區：Targeted 的目標清單是空的時，按 **從範例開始**，範例會直接放進清單。
- Excel：右上角問號圖示（**使用說明與快捷鍵**）→ **下載目標清單範例 XLSX**。程式資料夾的 `examples/targets.xlsx` 也是同一份。

XLSX 表頭的每一格都附有填法註解。

## 欄位

工作表名稱是 `Targets`，第一列是欄名。

| 欄名 | 必填 | 填什麼 | 例 |
| --- | --- | --- | --- |
| `label` | 是 | 目標名稱，不可重複；會成為結果的欄名 | `5-hmdC` |
| `mz` | 是 | 定量離子的 m/z | `258.1085` |
| `expected_rt_min` | 是 | 預期 RT（分鐘） | `9.0` |
| `role` | 是 | `analyte` 或 `istd` | `analyte` |
| `istd_pair` | 否 | 配對內標的 `label`；內標列留空 | `d3-5-hmdC` |
| `cid_nl_loss_da` | 否 | 中性丟失（Da） | `116.0474` |
| `delta_mass_mz` | 否 | 伴隨離子與 `mz` 的精確質量差，逗號分隔 | `+1.0021, +4.0052` |

- 值要填數字或文字，不要用公式。
- 也可以用 CSV 或 TSV，欄名相同。
- 從工作區匯出的 XLSX 可能多兩張工作表：`Delta Mass`（每個伴隨離子一列）與 `Delta Mass Settings`（整份清單共用的門檻）。照原樣保留即可；不接受其他工作表。
- 預期 RT 只用來辨認是哪一個峰，不會裁掉搜尋範圍。

## 特異性：怎麼確認是這個化合物

`cid_nl_loss_da` 與 `delta_mass_mz` 決定除了 m/z 與 RT 之外還要看什麼證據。

| 填法 | 判斷方式 |
| --- | --- |
| 兩欄都空白 | MS1 only：只看 m/z（20 ppm）與 RT |
| 只填中性丟失 | 用 MS2 是否見到這個中性丟失來挑峰與確認 |
| 只填 Δm/z | 同一 RT 要同時見到伴隨離子 |
| 兩欄都填 | 兩個條件都要在同一個峰上符合 |

常用的中性丟失：dR `116.0474`、R `132.0423`、MeR `146.0579`。

> 沒有採到 MS2 不算中性丟失的證據。配對內標已計入、且分析物的峰在預期位置時，分析物可以不靠自己的中性丟失計入。

## Delta Mass：伴隨離子怎麼填

伴隨離子是和目標在同一 RT 一起出現的其他 MS1 離子，例如同位素或標記物。

- **基準**：這一列的 `mz`，也就是定量離子。
- **Δm/z**：伴隨離子的 m/z 減去基準的 m/z，填精確質量差，正負都可以。

| 這一列的 `mz`（基準） | 伴隨離子的 m/z | `delta_mass_mz` 填 |
| --- | --- | --- |
| `300.1000` | `306.1201` | `+6.0201` |
| `300.1000` | `301.1021`、`304.1052` | `+1.0021, +4.0052` |

填了 Δm/z 的目標，一定要見到伴隨離子才算符合，不會退回 MS1 only。

## 在工作區編輯

在 Targeted 的目標清單按 **檢視與編輯**，開啟 **編輯目標清單**。

1. 選目標：拖曳框選列號，<kbd>Ctrl</kbd> 加選，<kbd>Shift</kbd> 連選；搜尋會選取符合的目標。
2. 批次設定：在上方填 **CID-NL 中性丟失（Da）** 或 **Delta Mass Δm/z**，按 **套用**。只寫入有填的欄。**設為 MS1 only** 會清空兩欄。
3. 單一目標的伴隨離子：點該列的 **Delta Mass Δm/z** 格，在下方展開的編輯區按 **＋ 伴隨離子**。
   - **Δm/z（伴隨 − 基準）**：精確質量差。
   - **強度比（伴隨 ÷ 基準，只記錄）**：填範圍如 `0.2–0.8`，只記錄，不拿來排除。
   - **比對峰形**：勾選時，伴隨離子的峰形要和基準相似。
   - 預覽圖以這一列的實際 m/z 畫出各離子。
4. 共洗脫與峰形門檻在 **進階：Delta Mass 判斷設定（整份清單共用）**，通常不必改。
5. 按 **完成**。要給其他批次用，按 **匯出清單 XLSX**。

## 匯入

把檔案拖到 Targeted 的 **匯入清單**，或按 **瀏覽**。

- 預覽會列出目標、預期 RT、角色、ISTD 配對與特異性。確認後按 **匯入**；已有清單時按鈕是 **取代目前清單**。
- 匯入只換目標清單，RAW 資料夾與上機資訊不變。
- 檔案上限 1 MiB，不支援 `.xls`。

## 當作 Untargeted 的內標清單

同一份清單可以直接用在 Untargeted 的 **內標清單**：

- 只讀 `role` 為 `istd` 的列，其他列略過。
- 只用中性丟失和目前方法相符的內標。例如 dR 方法不用 R 內標；不相符的列標為不適用，不是 ND。
