02 · 沿著共同核心

從候選訊號到可交付的格值

產品流程的主軸是 Discovery → Alignment → 必要時 Backfill。下面把中間的峰觀察和最後的輸出決策一起標出，讓模組分工更容易看懂。

  1. 1
    Discovery · 找候選依搜尋範圍讀 RAW，找可能的訊號從儀器資料取得候選特徵與色譜訊號，保留它們從哪裡來的證據。

    Targeted 從目標清單限定要交付的目標；Untargeted 在設定的證據空間中探索。Discovery 產生候選和來源事實，Extraction 負責 Targeted 執行協調與抽取工作。

    • 進來：RAW、設定、搜尋範圍。
    • 交出：候選訊號與帶來源的觀察資料。

    discovery/、extraction/

    繼續閱讀：Discovery、模組責任

  2. 2
    Peak evidence · 看峰把色譜訊號變成可檢查的峰觀察辨認峰的位置、邊界和面積，讓後續判斷有可追溯的依據。

    這一步處理物理訊號與候選峰證據。它還不是最終 matrix 的值；同一筆觀察仍須經過跨樣本和輸出格的決策。

    • 進來：候選色譜訊號。
    • 交出：峰觀察、候選假說與積分證據。

    peak_detection/

    繼續閱讀：定量脈絡、證據與決策

  3. 3
    Alignment · 跨樣本判斷哪些觀察屬於同一組把各樣本的證據對齊，建立可比較的目標或特徵群。

    Alignment 的 CrossSample owner 管群組成員與身分；共享處理核心讓兩種工作模式沿用同一套跨樣本判斷。

    • 進來：各樣本的峰觀察與來源。
    • 交出：完成的跨樣本群組與每個樣本的對應情形。

    alignment/

    繼續閱讀：Alignment、共享處理核心

  4. 4
    Backfill · 有需要才回填某個格的證據不足時，有限度地再查一次已經有目標或群組 owner，才對缺漏的樣本格做 bounded revisit。

    Backfill 可能補出新觀察，也可能回報無法修復。它不憑空建立新群組，也不自行挑選輸出值；證據足夠的格不需要這一步。

    • 進來：已建立的目標／群組與不足的樣本格。
    • 交出：補充觀察或明確的無修復結果。

    alignment/backfill/

    繼續閱讀：Backfill、產品用語

  5. 5
    Cell decision & output · 交付決定每個結果格要寫值，還是留空先完成格值決策，再依工作模式寫成 workbook 或 matrix。

    共享的 cell decision 決定值或 no-write；Targeted 和 Untargeted 各自決定要保留哪些列、怎麼呈現。Output renderer 只把已完成的結果寫成檔案，不重算科學證據。

    • 進來：對齊完成的證據與補缺結果。
    • 交出：可審閱的 Excel workbook、TSV 或明確選用的報告。

    alignment/cell_decision/、output/

    繼續閱讀：格值決策、Matrix
