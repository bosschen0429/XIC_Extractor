02 · 依問題找段落

我現在卡在哪一個概念？

  • 候選特徵從哪裡來？ Discovery
  • 一段訊號怎麼變成峰？ 定量與峰觀察
  • 兩種模式為何能共用核心？ Shared kernel
  • 不同樣本怎麼對齊？ Alignment
  • 缺漏的格能不能補？ Backfill
  • 為什麼有些格留空？ Decision policy
  • Matrix 到底裝什麼？ Quant matrix
  • 這些專有名詞怎麼讀？ 產品詞彙
  • 各模組誰負責什麼？ Architecture
  • 執行中斷或重跑怎麼管理？ Runtime
  • Untargeted CID-NL 完成後怎麼看證據？ Inspector
