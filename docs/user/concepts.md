# 判讀原理

讀結果時最容易誤會的幾件事，以及結果是怎麼產生的。

## 面積、計入、需檢查是三件事

| 問題 | 看哪裡 |
| --- | --- |
| 量到多少？ | 面積（`Area`、矩陣格值） |
| 算不算偵測到？ | 計入偵測（`Counted Detection`） |
| 要不要再看一眼？ | 需檢查（`Review`、需先看） |

三個答案各自獨立：

- 有面積不一定計入，例如峰形不合格，面積仍保留給你判斷。
- 計入的結果也可能需要看，例如峰有肩峰。
- 需檢查只決定閱讀順序，不改判定或數值。

## ND、空白與 0 不一樣

| 看到的 | 意思 |
| --- | --- |
| `ND` | 未偵測：沒有找到符合條件的峰；不等於樣本裡一定沒有 |
| 空白 | 沒有可靠的定量值，例如多峰無法判定；不是 0，也不代表沒有訊號 |
| `0` | 量到的面積是 0 |

不要把空白直接改成 0。要知道原因，看該格的判定說明或 XIC。

## 從 RAW 到矩陣

以 Untargeted 為例：樣本 A、B 在相近的 m/z 與 RT 有峰，樣本 C 沒有。

1. **找候選（Discovery）**：方法提供線索，例如 A 的 MS2 見到 dR 中性丟失，指出 A 有一個值得追的 MS1 峰。線索不是鑑定；C 沒採到 MS2 也不代表沒有這個化合物。
2. **找峰與積分**：在 XIC 上找出峰的邊界並計算面積。旁邊較大或較漂亮的峰，不一定就是線索指的那個峰。
3. **跨樣本對應（Alignment）**：A、B 的 m/z、RT 與峰相容，歸為同一群組，成為矩陣的一列（feature）。
4. **回填（Backfill）**：群組成立後，回到 C 的 RAW 在預期位置附近重找。找到可用的峰才填值；找不到就留空，不會從 A、B 的面積推算。
5. **每格判定**：每一格決定填哪個值，或為什麼不填。只有判定完成的群組進矩陣。

Targeted 走同樣的流程，差別是目標清單事先決定了要找什麼，每個目標固定一列。

## 內標

- Targeted：配對內標在同一樣本已計入，且分析物的峰在預期的相對位置時，分析物可以不靠自己的中性丟失計入。
- 面積比要自己算：在 `面積` 工作表，分析物與內標排在相鄰欄，例如 `=B5/D5`。
- 整理矩陣時，內標對應的列一律保留。

## feature 不是化合物

同一個化合物的同位素、adduct 或聚集離子可能各自成為一列。要收斂成一列，用整理矩陣的 **同化合物收斂**。

整理矩陣只篩選與收斂列，不做 normalization、批次校正或統計。

## 詞彙

| 詞 | 意思 |
| --- | --- |
| XIC | 指定 m/z 的強度隨時間變化的曲線 |
| CID-NL | 碰撞誘導解離後的中性丟失，用來找特定結構的離子 |
| 中性丟失 | 前驅離子與產物離子的質量差（Da） |
| Delta Mass | 同一 RT 一起出現的 MS1 離子之間的質量差型態 |
| 基準 | Delta Mass 的參考離子；Targeted 是該列的 m/z，Untargeted 是最輕的離子 |
| 伴隨離子 | 和基準在同一 RT 一起出現的其他離子 |
| feature | 跨樣本對應成同一群組的訊號，矩陣的一列 |
| 矩陣 | feature × 樣本的面積表 |
| 回填（Backfill） | 群組成立後，回到缺值的樣本重找峰 |
| ISTD | 內標，加入樣本的同位素標記標準品 |
