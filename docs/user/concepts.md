# 判讀原理

讀結果時最容易誤會的幾件事，以及結果是怎麼產生的。

## 面積、計入、需要看是三件事

| 問題 | 看哪裡 |
| --- | --- |
| 量到多少？ | 面積（`Area`、矩陣格值） |
| 算不算偵測到？ | 計入偵測（`Counted Detection`） |
| 要不要再看一眼？ | Targeted 的依據與疑點（`依據`、`疑點`），見[依據與疑點](targeted.md#依據與疑點) |

三個答案各自獨立：

- 有面積不一定計入，例如峰形不合格，面積仍保留給你判斷。
- 計入的結果也可能有疑點，例如峰有肩峰。
- 需要看與 Targeted 的 **需先看** 清單只決定閱讀順序，不改判定或數值。

## ND、空白與 0 不一樣

| 看到的 | 意思 |
| --- | --- |
| `ND` | 未偵測：沒有找到符合條件的峰；不等於樣本裡一定沒有 |
| 空白 | 沒有可靠的定量值，例如多峰無法判定；不是 0，也不代表沒有訊號 |
| `0` | 量到的面積是 0 |

不要把空白直接改成 0。要知道原因，看 Targeted 的 `依據` 或 XIC。

## 從 RAW 到矩陣

以 Untargeted 為例：樣本 A、B 在相近的 m/z 與 RT 有峰，樣本 C 沒有。

1. **找候選（Discovery）**：方法提供線索，例如 A 的 MS2 見到 dR 中性丟失，指出 A 有一個值得追的 MS1 峰。線索不是鑑定；C 沒採到 MS2 也不代表沒有這個化合物。
2. **找峰與積分**：在 XIC 上找出峰的邊界並計算面積。旁邊較大或較漂亮的峰，不一定就是線索指的那個峰。
3. **對齊（Alignment）**：A、B 的 m/z、RT 與峰相容，歸為同一個 feature，成為矩陣的一列。
4. **回填（Backfill）**：feature 成立後，回到 C 的 RAW 在預期位置附近重找。找到可用的峰才填值；找不到就留空，不會從 A、B 的面積推算。
5. **每格判定**：每一格決定填哪個值，或為什麼不填。只有判定完成的 feature 進矩陣。

Targeted 走同樣的流程，差別是目標清單事先決定了要找什麼，每個目標固定一列。

## ISTD

Targeted 的常見情況：某個分析物濃度低，MS2 沒有被觸發，自己沒有中性丟失證據。只要同一樣本的配對 ISTD 已計入、分析物本身的 MS1 峰完整，且峰頂落在相對 ISTD 的預期位置，它仍可計入偵測。同位素標記 ISTD 和分析物一起洗脫，所以 ISTD 替這個位置的峰確認了身分。

反過來也成立：ISTD 已計入時，落在預期位置之外的峰會被視為別的訊號，記為 `ND`，即使它自己見到中性丟失。預期位置怎麼定，見[目標清單的 `expected_rt_min`](targeted.md#欄位)。

Untargeted 整理矩陣時，ISTD 對應的列一律保留。

## feature 不是化合物

同一個化合物的同位素、adduct 或聚集離子可能各自成為一列。要收斂成一列，用整理矩陣的 **同化合物收斂**。

整理矩陣只篩選與收斂列，不做 normalization、批次校正或統計。

## 詞彙

說明頁每個概念只用左欄的詞；畫面、Excel 或檔案裡的標籤照原字列在右欄。

| 詞 | 意思 | 畫面或檔案上的名稱 |
| --- | --- | --- |
| XIC | 指定 m/z 的強度隨時間變化的曲線 | **看 XIC**、**載入 XIC** |
| 中性丟失 | 前驅離子與產物離子的質量差（Da），由碰撞誘導解離（CID）產生，用來找特定結構的離子 | CID-NL（方法名稱）、`cid_nl_loss_da`、標籤裡的 NL |
| Delta Mass | 同一 RT 一起出現的 MS1 離子之間的質量差型態 | `delta_mass_mz` |
| 基準 | Delta Mass 的參考離子；Targeted 是該列的 m/z，Untargeted 是最輕的離子 | |
| 伴隨離子 | 和基準在同一 RT 一起出現的其他離子 | |
| ISTD | 內標（internal standard）：加入樣本的同位素標記標準品 | `role` 的值 `istd` |
| 計入偵測 | 算作偵測到；簡稱計入 | **計入**、`Counted Detection` |
| 判定 | 程式對一筆結果或一格的結論，例如計入、`ND` 或留空 | `Counted Detection`、`identity_reason` |
| 依據 | Targeted 一筆結果依據的觀察，一個固定標籤 | `依據` |
| 疑點 | Targeted 一筆結果不確定的地方，0 到多個固定標籤 | `疑點` |
| 需要看 | 依據是標「需要看」的標籤，或有疑點的 Targeted 結果 | 強調色 |
| 需先看 | Targeted 整批的閱讀順序：每個目標裡占 20% 以下的那一方判定；沒有明顯多數時是需要看的結果 | **先看這 N 筆** |
| 對齊 | 把各樣本相容的峰歸為同一個 feature | Alignment、`alignment_*` |
| feature | 對齊後的一組訊號，矩陣的一列；不等於已確認的化合物 | `feature_id` |
| 矩陣 | feature × 樣本的面積表 | `alignment_matrix.tsv`、**整理矩陣** 產生的 `analysis_matrix.tsv` |
| 回填（Backfill） | feature 成立後，回到缺值的樣本重找峰 | **回填** |
| 上機資訊 | 上機時的序列表檔案（Word、Excel、CSV 或 TSV），提供樣本角色、組別與排除 | **上機資訊** |
| 結果存放位置 | 放所有分析結果的上層資料夾 | **結果存放位置** |
| 結果資料夾 | 每次分析在結果存放位置裡建立的資料夾 | |
