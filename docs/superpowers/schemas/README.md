Schemas define machine-checkable JSON contracts and formal validation shapes
consumed by a current checker. They are not implementation goals, validation
result buckets, review-story galleries, design specs, or historical design
archives. No checker-consumed schema is tracked here at present; add one only
together with its consumer.

The [Matrix publication contract](../../product/quant-matrix.md#matrix-publication)
describes current numeric publication and its decision owners.
