# Standard Peak T5D contraction v1

Evidence status: `production_candidate` (no-RAW structural and typed-contract evidence).

T5D removes the separate Standard Peak product route. Owner Backfill remains the
only Backfill decision owner and the existing primary Alignment writer remains
the only normal Matrix writer. Standard Peak is now represented only by:

- `xic_extractor.diagnostics.standard_peak_hold_diagnostic`, an in-process,
  typed explanation contract over a requested subset of a complete live
  Owner-Backfill replay;
- retained low-level overlay, shift-aware, calibration, gallery, and Targeted
  oracle/rendering tools named in `capability_disposition_v1.tsv`;
- historical source-sealed validation artifacts, which are navigation and
  falsification inputs only and cannot be replayed into ProductWriter authority.

The typed diagnostic planner requires exact `ProcessingRunSpec` sample
population/order, recomputes `ProductionDecisionSet` through
`build_production_decisions()`, rejects duplicate or unknown keys, and mints
subjects only for non-writing `review_rescue` decisions whose Owner reason is
in the closed diagnostic-eligibility set. Accepted evidence can explain possible
DDA missingness, multi-peak, wrong-peak, mode, identity, or shape/shift ambiguity.
The result type has no Matrix value, SUPPORT/activation decision, publication
target, or writer receipt.

Deleted live surfaces include the Standard Peak authority bundle, shadow
activation inputs, productization transaction, activation-scope/heldout
productization gates, chunk consolidator/formal sidecar, source republisher,
preset/machine orchestrators, stage replay, and readiness checker. The historical
T0 packet remains unchanged at
`docs/superpowers/validation/standard_peak_shared_evidence_t0_v1/`; this T5D
manifest is the final SP-001–SP-055 disposition authority.
