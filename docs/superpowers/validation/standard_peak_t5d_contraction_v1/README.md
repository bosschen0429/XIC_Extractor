# Standard Peak T5D contraction v1

Evidence status: `production_candidate` (no-RAW structural evidence).

T5D removes the separate Standard Peak product route. Owner Backfill remains the
only Backfill decision owner and the existing primary Alignment writer remains
the only normal Matrix writer. Standard Peak is now represented only by:

- retained low-level overlay, shift-aware, calibration, gallery, and Targeted
  oracle/rendering tools named in `capability_disposition_v1.tsv`;
- source-sealed historical validation artifacts that can falsify or explain old
  results but cannot mint current product authority.

T5D does not mint `diagnostic_eligible` from Backfill reason strings and does not
claim that a supplied `ProcessingRunSpec` binds an independently supplied Matrix
to the same attempt. The current owners provide neither contract. Retained tools
may still help an operator inspect possible DDA missingness, multi-peak,
wrong-peak, mode, identity, or shape/shift ambiguity, but without complete
original-owner subject/run rehydration the resulting semantic claim is
`unavailable`; it cannot promote or write.

T5B established that the 84-cell packet predates current typed/hash provenance
and cannot manufacture product authority. T5D therefore keeps the packet
validator as a historical integrity/oracle surface, deletes its ownerless
writer, and removes the registered scope from the live authority manifests.
The existing 511-cell Owner Backfill and 95-cell CID-NL scopes are unchanged.

Deleted live surfaces include the Standard Peak authority bundle, shadow
activation inputs, productization transaction, activation-scope/heldout
productization gates, chunk consolidator/formal sidecar, source republisher,
preset/machine orchestrators, stage replay, and readiness checker. The historical
T0 packet remains unchanged at
`docs/superpowers/validation/standard_peak_shared_evidence_t0_v1/`; this T5D
manifest is the final SP-001–SP-055 disposition authority.
